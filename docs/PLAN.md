# Lexicon Legion — план работ

Волны короткие, каждая заканчивается PR и живой проверкой владельцем. Дисциплина — как в
Ties Break / Onsight: одна ветка на волну, гейт тестов перед PR, авто-фиксы после ревью сразу.

## Волна 0 — разведка ✅ (07.10)

Тест 302 слова, результат, вердикт, спека, план. Этот документ.

## Волна 1 — скелет и первый бой

Цель: установить на телефон и выучить первые слова.

- Структура репо по спеке §7; `package.json`, esbuild-сборка, `node --test`.
- `src/core`: перенос `srs.js`, `selection.js`, `store-migrate.js`, `leveling.js`, `streak.js`,
  `matching.js` из Tense Titans → одна форма на слово; тесты переносятся и чинятся первыми.
- `groups.js`: загрузка каталога и групп, слияние слов по `id`, дистракторы по части речи.
- Экраны: Дом (минимум), Сессия с режимом «узнавание» и «воспроизведение», Настройки (бюджет, голос,
  экспорт/импорт).
- PWA-оболочка: `sw.js`, `manifest.json`, иконки.
- Данные: `tools/book2lemmas.py`, `pick.py`, `make_group.py`; группа **cestus-d** (полоса 3.0–3.5,
  ~1 100 слов) с глоссами. Глоссы пишутся порциями по 300–400 слов — первая порция в этой волне,
  в группу входит то, что отглоссировано; остальное — волна 2.
- Импорт результата разведки: 90 незнакомых слов теста идут первыми.
- GitHub Pages, владелец ставит на телефон.

Гейт: тесты зелёные; сессия из 20 карточек проходится на телефоне офлайн; стор переживает перезагрузку.

## Волна 3 — контекст, голос, группы C и B

- Режим «контекст» (фраза из источника с пропуском).
- Озвучка ответа, выбор акцента.
- Группы **cestus-c** (2.5–3.0, ~700) и **cestus-b** (2.0–2.5, ~350).

Гейт: доля предложений с «дыркой» по модели ≤ 17 % (D+E выучены на ≥ 70 %).
