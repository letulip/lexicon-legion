# Разведка словаря: *The Cestus Deception* (Steven Barnes, 2004)

Дата: 2026-10-07. Цель — понять, какие слова книги читатель не знает, и из каких полос частотности
собирать словарь приложения.

## Метод

1. Текст из EPUB (3 HTML-части) → 636 569 символов, 8 068 предложений, **104 412 слов текста**.
2. Токены лемматизированы (`simplemma`), итого **7 509 лемм**. Для каждой: частота в книге,
   доля написаний с заглавной (≥ 0.5 → имя собственное), частота в английском по `wordfreq`
   (шкала Zipf: 5 = 10 раз на миллион слов, 4 = 1 на миллион, 3 = 1 на 10 миллионов).
3. Полосы Zipf и их доля в тексте книги:

| Полоса | Zipf | Лемм в книге | Доля текста | Пример |
|---|---|---|---|---|
| имена и термины вселенной | 0 / заглавные | ~1 000 | 5,6 % | Obi-Wan, Nautolan, comlink |
| сверхредкие | < 1.5 | ~250 | 0,2 % | caterwaul, mirthlessly |
| A очень редкие | 1.5–2.0 | 111 | 0,2 % | glower, roil, unnerve |
| B редкие | 2.0–2.5 | 274 | 0,6 % | askance, writhe, impassive |
| C книжные | 2.5–3.0 | 556 | 1,4 % | chasm, sneer, hubris |
| D продвинутые | 3.0–3.5 | 911 | 2,8 % | cunning, ledge, devour |
| E уверенный B2 | 3.5–4.0 | 1 082 | 4,5 % | glance, summon, reckon |
| F B1–B2 | 4.0–4.5 | 1 111 | 6,7 % | barely, courage, warn |
| G базовые | 4.5–5.0 | 859 | 9,2 % | claim, severe, proud |
| ядро | ≥ 5.0 | ~800 | 68,8 % | the, said, know |

(«Лемм в книге» — после фильтра имён, дефисов и слов короче 3 букв.)

4. Тест: стратифицированная выборка — 32 / 50 / 50 / 50 / 50 / 40 / 30 слов из полос A–G
   (всего 302), к каждому — краткий русский перевод и фраза из книги как контекст. Формат:
   4 варианта перевода (дистракторы — переводы других слов теста той же части речи) + «не знаю».

## Модель результата

- Знание полосы `k_b = (верно − мимо/3) / n` — поправка на угадывание при 4 вариантах.
- Доля непонятных слов текста `U = Σ_b share_b · (1 − k_b)`; сверхредкие считаются по полосе A,
  имена показываются отдельно (их не «знают», их узнают по ходу книги).
- Оценка словарного запаса `V ≈ 739 + Σ_b N_b · k_b`, где `N_b` — число **семейств слов** полосы:
  список `wordfreq` (large), отфильтрованный по словарю `/usr/share/dict/words` и очищенный от
  прозрачных производных (-ly, -ness, un-, re- … при наличии более частой основы). Получается
  7 382 / 6 246 / 5 495 / 4 275 / 2 882 / 1 762 / 1 014 семейств для полос A–G и 739 для ядра,
  всего ≈ 29 800 — согласуется с литературной оценкой словаря взрослого носителя (20–35 тыс. семейств).
  Сырые списки `wordfreq` (69 797 слов в полосе A и т. д.) для этого не годятся: там опечатки,
  имена и словоформы.
- Контекст: открытие фразы перед верным ответом помечает слово как «узнаю в тексте, не в отрыве».
  Такие слова — лучший кандидат в активный словарь (дёшево перевести из пассива).

## Ожидание

Ощущение читателя — «20–25 % слов с трудом понимаю». По долям текста это невозможно без потерь
в полосах F–G: полосы A–E вместе дают лишь 9,5 % текста. Правдоподобный сценарий — ощущение
складывается из плотных описательных абзацев (где редкие слова идут подряд) плюс имена/термины
(5,6 %). Тест покажет, где именно проходит граница.
