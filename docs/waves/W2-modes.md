# Волна 2 — режимы (спека и план)

Дата: 08.10.2026. Запрос владельца: шесть пунктов после первого дня с v0.2.0.

## Решения по пунктам

### 1. Письмо с подсказками по шагам
Режим ввода получает маску слова над полем: `_ _ _ _ _`. Кнопка «Подсказка» открывает случайные
буквы шагами, **шаг = четверть букв слова** (не меньше одной), всего не больше половины слова:
3–4 буквы — одна подсказка из одной буквы, 5–7 — две по одной, 8–11 — две по две, 12+ — две по три.
Когда бюджет исчерпан, кнопка гаснет, остаётся «Не знаю». (Поправка владельца 08.10: было «2 + 2 буквы»,
в коротких словах оставалась одна скрытая.) Ответ с подсказкой **засчитывается, но уровень не растёт** (XP 5 вместо 15),
слово возвращается в очередь на следующий заход. Без подсказок — как раньше.
Первая буква больше не открывается первым шагом: случайные позиции честнее.

### 2. Режим «Новые слова» — порциями
Отдельная кнопка на Доме. Порция = 10 слов (настройка 5/10/15), берётся из дневного бюджета.
Четыре этапа внутри одного захода:
1. **Знакомство** — карточка слова: слово, часть речи, значения, фраза из книги, озвучка; листается.
2. **Узнавание** — те же 10, выбор перевода.
3. **Обратное** — перевод → слово.
4. **Письмо** — ввод слова (с подсказками по п. 1).
Промах на любом этапе возвращает слово в хвост этого же этапа, пока все 10 не пройдут.
Уровень растёт естественно через SRS: после захода слово на уровне 3 («узнаю»),
дальше — только повторения.

### 3. «Повторение» — ограничено и без новых
Текущий «бой» становится «Повторением»: только слова, у которых подошёл срок, плюс слова
«в работе». Новых в нём нет вовсе. Размер захода — настройка (10/20/30, по умолчанию 20),
на Доме видно «к повторению N», кнопка «Ещё заход» в итогах, пока очередь не пуста.

### 4. «Работа над ошибками»
Коллекция «ошибок» = слова, на которых был промах или «не знаю» и которые ещё не поднялись
обратно до уровня 3. Это и есть «все неотвеченные и ошибочные прошлые слова» — они не теряются,
пока не исправлены. Экран: список (слово, значение, число промахов, когда последний раз),
кнопка «Разобрать» — заход письмом (с подсказками) по этим словам. Верный ввод без подсказки
поднимает слово сразу до уровня 3 и выводит из коллекции; с подсказкой — остаётся.
Сортировка списка: больше промахов и ниже уровень — выше.

### 5. Как растёт основной режим
Логика, без изменений в замысле, теперь видимая:
- Очередь повторения = слова, у которых прошёл интервал уровня (1, 2, 3, 3, 4, 5, 6, 21 дней
  для уровней 3…10). Выученное слово возвращается всё реже, легат — раз в три недели.
- На 10 новых в день в установившемся режиме набегает примерно 40–60 повторений в день
  (каждое слово за жизнь проходит ~8 повторений, размазанных по растущим интервалам).
  Заход ограничен настройкой, лишнее ждёт следующего захода или завтра.
- Порядок: сначала самые давно не виденные, затем заход **перемешивается** (новое в этой волне —
  раньше шёл строго по давности), чтобы одни и те же слова не стояли одной и той же парой.
- Просрочка: пропущенные дни не копят бесконечно — кривая забывания роняет уровень просроченного
  слова (с льготным окном ≥ 5 дней), и оно возвращается в работу, а не в хвост.
Бесконечного роста нет: ограничивают дневной бюджет новых и интервалы.

### 6. Что такое «запомнено»
Было: «в строю» = уровень 3 (три верных узнавания). Это слишком рано. Теперь пять статусов:

| Статус | Уровень | Что потребовалось |
|---|---|---|
| новое | — | не встречалось |
| в работе | 0–2 | узнавание, обратное |
| узнаю | 3–5 | прошло узнавание + 1–2 письма с интервалом |
| **выучено** | 6–9 | ≥ 3 верных письма/контекста без подсказок с интервалами 1–3 дня |
| легат | 10 | 7+ верных письма, последние с интервалами 4–6 дней |

Узнавание и обратное никогда не поднимают выше 3; выше — только письмо и контекст **без подсказок**.
Промах роняет на два уровня. На Доме считается «выучено» (≥ 6), «узнаю» (3–5), «в работе», «новых».
Итого «запомнено» = слово несколько раз переведено в обе стороны и минимум трижды написано без
ошибок с перерывами в дни — как и просил владелец.

### Попутный дефект
Слова из импорта разведки (уровень 0 без ответов) не попадали ни в «новые», ни в «в работе» —
очередь их не видела. Исправляется: слово без ответов считается новым и идёт первым.

## План

Одна ветка `wave-2`, версия 0.3.0, схема стора 2 (настройки `learnBatch`, `reviewSize`;
миграция переносит старый `sessionSize`).

| Шаг | Что | Кто |
|---|---|---|
| 1 | Ядро: `srs.js` статусы и ответ с подсказкой/режим «ошибки»; `selection.js` очереди повторения/новых/ошибок с перемешиванием; `hints.js` маска и шаги; стор v2 + миграция; тесты на всё | родительская сессия |
| 2 | UI: Дом с тремя режимами и новыми счётчиками; заход «Новые слова» (4 этапа); «Повторение»; экран «Ошибки» + заход; маска подсказок в письме; итоги по видам | родительская сессия |
| 3 | Гейт: `npm test`, живая проверка в превью всех трёх заходов и подсказок, мобильная ширина | родительская сессия |
| 4 | Ревью диффа свежими глазами: один тонкий read-only агент (Explore), вердикт + список дефектов; AUTO-корзина чинится сразу | агент-ревьюер |
| 5 | PR, обновление README/SPEC | родительская сессия |

Почему не билдер-агент на UI: объём ~400 строк в одном файле `app.js`, контекст уже в сессии;
второй исполнитель в том же файле дороже и рискованнее, чем один. Агент нужен только там, где
ценны свежие глаза — на ревью.
