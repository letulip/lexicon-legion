# Lexicon Legion — спецификация v1

Статус: черновик на утверждение владельцу, 07.10.2026. Основание —
[результат разведки](analysis/result-2026-10-07.md) и [анализ книги](analysis/cestus-deception.md).

## 1. Что это

Offline-first PWA для взрослого русскоязычного читателя английской литературы: берёт слова
«книжного» уровня (Zipf 2–4), которые читатель знает через одно, и переводит их из пассива в актив
по SRS — тем же игровым циклом, что в Tense Titans, но без детской обвязки.

Цель v1, измеримая: для книги *The Cestus Deception* снизить долю предложений с незнакомым словом
с 32 % до ≤ 10 % (это ≈ 900 выученных слов полос C–E).

## 2. Принципы (унаследованы от Tense Titans)

- Plain HTML/CSS/JS, ES-модули, esbuild только для релизной сборки в `dist/`, без рантайм-зависимостей.
- PWA: `sw.js` cache-first + `manifest.json`, полностью офлайн после первой загрузки.
- Прогресс в `localStorage`, версия схемы + последовательные аддитивные миграции, бэкап перед миграцией.
- Чистая логика (SRS, выбор, стор) — в `src/core/*`, DOM-free, под `node --test`.
- GitHub Pages, ветки + PR, мержит владелец. Каждый релиз: bump `CACHE` в `sw.js` и `APP_VERSION`.

## 3. Масштабируемость словаря — главное архитектурное требование

### 3.1 Группы слов — это данные

```
data/
  catalog.json              — реестр групп: id, title, description, count, level, source, version
  groups/
    cestus-c.json           — одна группа = один файл
    cestus-d.json
    ...
```

Группа:

```json
{
  "id": "cestus-d", "title": "Cestus Deception · продвинутые", "version": 1,
  "source": { "kind": "book", "title": "The Cestus Deception", "lang": "en" },
  "level": { "zipf": [3.0, 3.5], "label": "продвинутые" },
  "words": [
    { "id": "ledge", "w": "ledge", "pos": "n", "ru": ["выступ, уступ (скалы, окна)"],
      "zipf": 3.41, "freq": 2, "tags": ["place"],
      "ex": [{ "t": "… the [ledge] …", "src": "cestus" }] }
  ]
}
```

Правила:

- **`id` слова глобален и стабилен** (лемма; при омонимии разных частей речи — `stalk_v`). Прогресс
  хранится по `id`, не по группе: одно слово в двух группах = один прогресс. Переименовывать id нельзя.
- Группа — самодостаточна: приложение не знает заранее ни числа групп, ни их имён. Новая группа =
  новый JSON + строка в `catalog.json` + путь в precache `sw.js`. Кода не касается.
- Порядок слов в группе = порядок подачи (сортировка по отдаче: частота в источнике × редкость).
- Переводы — массив (несколько значений), первое — основное; примеры — массив с указанием источника.
- Поле `tags` — для будущих тематических срезов («эмоции», «движение», «разговорное») поверх групп.

### 3.2 Конвейер создания групп (`tools/`, Python)

1. `book2lemmas.py <epub|txt>` → `lemmas.csv` (лемма, частота, Zipf, доля заглавных, примеры). Уже
   написан в виде скрипта разведки; переносится в репо.
2. `pick.py lemmas.csv --band 3.0 3.5 --min-count 1` → `words.tsv` (кандидаты по полосе, без имён).
3. Глоссы: `words.tsv` дополняется колонками `pos`, `ru` — вручную/с помощью ассистента порциями
   по ~300–500 слов (как для теста). Масштабный путь: `gloss_wiktionary.py` — черновые переводы из
   дампа Wiktionary (kaikki.org, en→ru), затем ручная правка. Это **единственный ручной шаг**.
4. `make_group.py words.tsv --id cestus-d --title …` → `data/groups/cestus-d.json` + запись в каталог.
5. `assess2seed.py result.json` → список точно незнакомых слов (для приоритета в группе).

Другие источники идут тем же путём: любая книга, субтитры (разговорный слой), пользовательский
список. Разговорная группа v2 — из частотного списка субтитров (SUBTLEX), отфильтрованного по
тем же полосам Zipf.

### 3.3 Пользовательские группы

«Мои слова»: добавить слово руками (слово + перевод + пример) — хранится в сторе, прогресс как у
всех. Экспорт/импорт стора включает их.

## 4. Модель обучения

### 4.1 Сортировка (triage) — вход в группу

Новая группа не идёт в очередь целиком. Пользователь прогоняет её «знаю / не знаю» по 50 слов
(показывается слово + часть речи, без перевода; по тапу — перевод для самопроверки). «Знаю» → слово
получает уровень 3 (сразу в расписание повторений, проверится через несколько дней — ловим
самообман); «не знаю» → уровень 0, в очередь новых. Сортировку можно прервать и продолжить.
Тест-разведка импортируется: его «не знаю/мимо» = уровень 0, «верно» = уровень 3.

### 4.2 SRS — модуль `src/core/srs.js` из Tense Titans

Переносится как есть с одним изменением: у слова **одна форма**, а не две (past/pp).
Уровни 0–10, `INTERVAL_DAYS` те же, кривая забывания с `peak` и льготным окном, «мимо» = −2 уровня.
Узнавание (выбор из 4) поднимает максимум до 3; выше — только воспроизведение (ввод).

### 4.3 Режимы карточки

| Режим | Что показано | Ответ | Потолок уровня |
|---|---|---|---|
| Узнавание | слово | 4 перевода | 3 |
| Обратное узнавание | перевод | 4 английских слова | 3 |
| Воспроизведение | перевод (+ первая буква после 5 с) | ввод слова | 10 |
| Контекст | фраза источника с пропуском + перевод | ввод слова | 10 |

Дистракторы — из той же части речи и соседних полос; проверка ввода — по буквам (как `isCorrect()`),
принимаются варианты написания (`-ise/-ize`, `-our/-or`).

### 4.4 Сессия

Ежедневная сессия ≈ 20 карточек: сначала просроченные повторения (least-recently-seen), затем
новые по дневному бюджету (настройка, по умолчанию 10). Выбор — `selection.js` из Tense Titans,
адаптированный под одну форму. Ответ озвучивается (SpeechSynthesis, en-US/en-GB по настройке).

### 4.5 Прогресс и мотивация

XP, уровни, дневная серия и заморозка серии — переносятся (`leveling.js`, `streak.js`).
Ачивки — минимальный набор (первые 100 слов, 7 дней, первая «центурия»). Без маскота и косметики.
Героическая метафора только в ранге слова: рекрут (0–2) → легионер (3–4) → центурион (5–6) →
ветеран (7–9) → легат (10).

## 5. Экраны

1. **Дом** — сегодня: сколько к повторению, бюджет новых, серия; кнопка «В бой»; список подключённых
   групп с прогрессом (выучено / в работе / не начато); каталог групп («призвать легион»).
2. **Сессия** — карточка в одном из режимов, подсказка после ответа (перевод, пример, озвучка),
   прогресс-бар, выход без потери.
3. **Сортировка** — быстрый проход по группе (см. 4.1).
4. **Слова** — поиск, фильтр по группе/рангу/«мимо», карточка слова (все переводы, примеры,
   история), ручная пометка «знаю» / «сбросить».
5. **Статистика** — выучено по полосам Zipf (та же шкала, что в тесте: виден прогресс по полосам),
   динамика по дням, «трудные слова».
6. **Настройки** — дневной бюджет новых, голос, тема, звук; экспорт/импорт стора (JSON-файл);
   сброс группы.

Мобильный портрет — основной вид (Android Chrome, установка на экран), десктоп — вторичный.

## 6. Стор

```js
{
  schemaVersion: 1,
  progress: { [wordId]: { lvl, due, peak, correct, wrong, lastSeen, src: groupId } },
  groups:   { [groupId]: { enabled, addedAt, triage: { pos, done } } },
  custom:   { [wordId]: { w, pos, ru, ex } },          // «мои слова»
  stats:    { xp, dayStreak, bestStreak, lastStudyDate, freezes, totalAnswers, totalCorrect, history: {date: n} },
  settings: { dailyNew: 10, sessionSize: 20, voiceURI, accent: 'en-US', sound, dark, rate },
  flags:    { onboarded, assessImported }
}
```

Инварианты Tense Titans действуют: `fillDefaults` только дополняет; миграции — только добавление
следующего шага; тест перехода в том же PR; бэкап `store.bak` перед миграцией; импорт проверяет форму.

## 7. Структура репозитория

```
index.html  app.js  sw.js  manifest.json  package.json
src/core/   srs.js selection.js store-migrate.js leveling.js streak.js matching.js groups.js
src/css/    чанки как в Tense Titans

tools/      конвейер групп (Python, venv не в репо)
test/       node --test
docs/       SPEC.md PLAN.md analysis/
```

## 8. Вне v1

Синхронизация между устройствами, аккаунты, аудио-произношение не из SpeechSynthesis, картинки,
генерация примеров, импорт книги прямо в телефоне. Всё это не блокирует масштабирование словаря —
оно обеспечивается форматом групп и конвейером.
